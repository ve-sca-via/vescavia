# Build Instructions

## Complete Build Process

Your website has a full optimization pipeline for images, videos, CSS, and JavaScript!

### Build Process Overview:

```bash
npm run build
```

This runs:
1. **Image & Video Optimization** (`npm run optimize`)
2. **CSS & JS Minification** (`npm run minify`)

### Individual Scripts:

- `npm run optimize` - Optimize images and videos only
- `npm run minify` - Minify CSS and JavaScript only
- `npm run build` - Run both optimization and minification

## Optimization Results:

### Current Minification:
- **CSS**: 15.10 KB → 10.48 KB (30.6% smaller)
- **JavaScript**: 8.04 KB → 4.66 KB (42.0% smaller)

### Image & Video Optimization:
- Images are compressed to 80% quality with progressive loading
- Videos are optimized with H.264 codec and web-friendly settings
- Large videos automatically resized to max 1920x1080

## How to Use:

### For New Images:

1. **Add images** to the root directory OR `images-original/` folder
   - ⚠️ **DO NOT** put images directly in `optimized/images/`
   - Place unoptimized source images in root or `images-original/`
2. **Run optimization**:
   ```bash
   npm run optimize:images
   ```
3. Images will be optimized and saved to `optimized/images/`
4. Update your HTML to reference `optimized/images/yourimage.jpg`

### For New Videos:

1. **Add videos** to the root directory OR `videos-original/` folder
   - ⚠️ **DO NOT** put videos directly in `optimized/videos/`
   - Place unoptimized source videos in root or `videos-original/`
2. **Run optimization**:
   ```bash
   npm run optimize:videos
   ```
3. Videos will be optimized and saved to `optimized/videos/`
4. Update your HTML to reference `optimized/videos/yourvideo.mp4`

### For CSS/JS Changes:

1. **Edit** `style.css` or `script.js`
2. **Run minification**:
   ```bash
   npm run minify
   ```
3. Minified versions are auto-generated

### Before Deployment:

Always run the complete build:
```bash
npm run build
```

### Optimization Options:

- `npm run optimize` - Optimize both images and videos
- `npm run optimize:images` - Optimize images only (skip videos)
- `npm run optimize:videos` - Optimize videos only (skip images)
- `npm run minify` - Minify CSS and JS only
- `npm run build` - Run everything (optimize + minify)

## Requirements:

### Node.js Dependencies:
```bash
npm install
```

This installs:
- `clean-css` - CSS minification
- `terser` - JavaScript minification
- `sharp` - Image optimization (optional but recommended)

### System Requirements:
- **FFmpeg** - Required for video optimization
  - Windows: `choco install ffmpeg` or download from ffmpeg.org
  - Mac: `brew install ffmpeg`
  - Linux: `sudo apt install ffmpeg`

## File Structure:

```
├── style.css              (source - edit this)
├── script.js              (source - edit this)
├── style.min.css          (generated - don't edit)
├── script.min.js          (generated - don't edit)
├── images-original/       (put new images here)
├── videos-original/       (put new videos here)
└── optimized/
    ├── images/           (optimized images - auto-generated)
    └── videos/           (optimized videos - auto-generated)
```

## ⚠️ Important Workflow:

**Source files (you edit these):**
- Images: `images-original/` or root directory
- Videos: `videos-original/` or root directory
- CSS: `style.css`
- JS: `script.js`

**Generated files (DO NOT edit directly):**
- `optimized/images/` - Auto-generated by optimize script
- `optimized/videos/` - Auto-generated by optimize script
- `style.min.css` - Auto-generated by minify script
- `script.min.js` - Auto-generated by minify script

## Important Notes:

- ✅ Always edit source files (`style.css`, `script.js`)
- ✅ Never edit `.min` files directly
- ✅ Run `npm run build` before every deployment
- ✅ Optimized files are git-tracked (committed to repo)
- ✅ Original large videos can be stored in `videos-original/`

## First Time Setup:

```bash
# Install dependencies
npm install

# Install FFmpeg (if not already installed)
# Windows: choco install ffmpeg
# Mac: brew install ffmpeg
# Linux: sudo apt install ffmpeg

# Run full build
npm run build
```

## Troubleshooting:

### "ffmpeg not found"
Install FFmpeg using instructions above

### "sharp module not found"
Sharp is optional. The script will copy images without optimization.
Install it for better optimization:
```bash
npm install sharp
```

### Large file warnings on git
Make sure large original files are in `videos-original/` and only optimized versions are committed.
